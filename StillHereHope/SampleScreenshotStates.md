# Sample Screenshot States

Use these app states for screenshots or App Store mockups:

1. Onboarding
   - Welcome card
   - Continue button

2. Home - fresh check-in
   - No mood selected
   - Quick support buttons visible

3. Home - result state
   - Mood selected: overwhelmed
   - Follow-up note filled
   - CheckInResultCard visible

4. Talk - standard support
   - User says: “I feel overwhelmed”
   - Short assistant reply visible

5. Talk - crisis escalation
   - Crisis banner visible at top
   - Escalation-only assistant message

6. Notes feed
   - Mixed notes with tags
   - Helpful/save buttons visible

7. Write note success
   - Success card after anonymous post

8. You
   - Mood history visible
   - Saved notes and impact card visible
