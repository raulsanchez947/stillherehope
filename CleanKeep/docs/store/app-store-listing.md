## Description

CleanKeep helps you tidy storage with a calmer, safer workflow.

Scan user-accessible folders to find files older than 365 days, likely junk, likely important files, and risky-looking downloads that deserve manual review. CleanKeep keeps decisions transparent: important file types are protected by default, selected items are moved to local quarantine, and file data is not uploaded.

Features:

- Find files not modified in more than 365 days.
- Sort likely junk from important documents, media, databases, tax files, and credentials.
- Flag executables and suspiciously named downloads for security review.
- Move selected files to local quarantine instead of permanent deletion.
- Use a native macOS folder picker for explicit scan consent.
- Keep scan results local to your device.

Important: CleanKeep is not a certified antivirus product. Security-review results are heuristic and should not be treated as confirmed malware detection.
